# Требования к внешним интеграциям

## Требования к безопасности

- Взаимодействие между системами разрешено только при помощи аутентифицированных запросов. Анонимные вызовы запрещены. Авторизация на действие не требуется (достаточно аутентификации инициатора запроса - собственника или внешней системы)

## Протоколы аутентификации и авторизации

-  Взаимодействие идет по REST API с использованием токенов аутентификации с ограниченным сроком действия.

## Взаимодействие между системами предприятия и внешней платформой
- В tenant-core-app встраиваются виджеты для открытия двери и шлагбаума по команде собственника. Данный виджет вызывает REST API внешней системы-открывателя. В вызове присутствует токен сфоормированный аутентифицированным в tenant-core-app пользователем, без данного токена внешняя система отвечает отказом.
- Внешняя система-открыватель при запросе на открывание по лицу или номеру автомобиля отправляет запрос в CRM где ищет указанное лицо или номер в базе разрешенных гостей. Запрос идет по REST API с токеном аутентификации созданном внешней системой.
