# Задание 1

## Классификация данных

### Публичные

#### Данные

- Объекты недвижимлсти и их характеристики
- Рекламные акции

#### Риски

- Утечка данных: Незначительный
  - Данные предназначены для публичного доступа.
- Искажение данных: Значительный
  - Может нанести ущерб репутации компании.


### Внутренние

#### Данные

- ФИО клиентов
- Связи клиентов с управляющими компаниями
- Отчеты по продажам
- Отчеты по платежам по услугам ЖКУ

#### Риски

- Утечка данных: Значительный
  - Может привести к конкурентным потерям.
- Потеря данных: Незначительный
  - Данные относительно легко восстановимы.
- Искажение данных: Значительный
  - Может повлиять на операционные процессы.


### Конфиденциальные

#### Данные

- Сделки по объектам недвижимости
- Платежи по услугам ЖКУ

#### Риски

- Утечка данных: Критический
  - Потеря конфиденциальности может нанести значительный ущерб.
- Потеря данных: Значительный
  - Восстановление может требовать времени и ресурсов.
- Искажение данных: Значительный
  - Нарушает процессы, основанные на этих данных.
- Некачественные данные: Значительный
  - Может ухудшить принятие решений.


### Секретные

#### Данные

- Персональные данные клиентов (паспорт, телфон, имейл)
- Платежные средства клиентов

#### Риски

- Утечка данных: Критический
  - Могут быть использованы конкурентами или хакерами.
- Потеря данных: Критический
  - Восстановление затратно и сложно.
- Искажение данных: Критический
  - Серьёзно подрывает бизнес-процессы.
- Некачественные данные: Значительный
  - Снижают эффективность бизнес-приложений.
- Обесценивание данных: Критический
  - Серьёзно подрывает бизнес-процессы.
